# typescript-template

[![code style: prettier](https://img.shields.io/badge/code_style-prettier-ff69b4.svg?style=flat-square)](https://github.com/prettier/prettier)

Template repository to start off a TypeScript project

## CodeQL on private repos

CodeQL scanning is free for public repos but needs
[GitHub Code Security](https://docs.github.com/en/get-started/learning-about-github/about-github-advanced-security)
on private ones. Without it the workflow fails, so turn it off:

```sh
gh variable set CODEQL_ENABLED --body false
```
